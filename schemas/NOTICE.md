# CycloneDX schemas

The JSON schemas are unmodified files from
[CycloneDX specification 1.5](https://github.com/CycloneDX/specification/tree/c320fc0f0b46873864927d9d5684eea7ba439728/schema),
tag commit `c320fc0f0b46873864927d9d5684eea7ba439728`.
The [Apache-2.0 license](CycloneDX-LICENSE) and
[source URLs and SHA-256 values](../conformance/third-party-inputs.json) are included.
Both referenced schemas are embedded, so validation does not retrieve network
resources or depend on installed schema files.
